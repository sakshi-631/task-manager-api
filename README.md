# Task Manager API

A simple REST API for managing tasks with features like create, update, delete, and view tasks.

## 🚀 Features
- Add new tasks
- View all tasks
- Update tasks
- Delete tasks

## 🛠 Tech Stack
- Python
- FastAPI (or Flask)
- Requests

## ▶️ How to Run
1. Clone repo
2. Install dependencies
3. Run server:
   uvicorn main:app --reload

## 📌 API Endpoints
- GET /tasks
- POST /tasks
- PUT /tasks/{id}
- DELETE /tasks/{id}
